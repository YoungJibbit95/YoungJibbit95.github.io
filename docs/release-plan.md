# Schrittweise Portfolio Releases

Jede Etappe endet mit einem verwendbaren Stand, einer Prüfung im Produktionsbuild und einer eigenen GitHub-Version. Größere Szenen werden einzeln ausgearbeitet.

| Release | Schwerpunkt                                    | Ergebnis                                                                                                                           |
| ------- | ---------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------- |
| 0.1     | Visuelle Grundlage und persönliche Vorstellung | Vollständiger Einstieg, Projektauswahl, kuratierte Projekttexte, eigene Illustrationen, Denkweise, Persönlichkeit und GitHub Pages |
| 0.2     | Nexus als erste ausführliche Geschichte        | Echte aktuelle Aufnahmen und eine animierte Erklärung vom einzelnen Gedanken zu verbundenen Clients                                |
| 0.3     | Cerebri nachvollziehbar machen                 | Ein kleines überprüfbares Planungsbeispiel mit Konflikten, Regeln und sichtbarer Freigabegrenze                                    |
| 0.4     | Engines und eigene Welten                      | Individuelle Szenen für Engine-Schichten und Spielwelten, ergänzt durch echtes Projektmaterial                                     |

## Qualitätskriterien je Etappe

- Die Seite bleibt mobil, per Tastatur und mit reduzierter Bewegung verwendbar.
- Animationen erklären den Inhalt und lassen sich abschalten.
- Projektstatus und Aufnahmen entsprechen dem tatsächlichen Stand.
- TypeScript, Produktionsbuild und relevante Browserprüfungen bestehen.
- GitHub Actions prüft denselben Commit, der veröffentlicht wird.
- Die live veröffentlichte Version wird nach dem Deployment kontrolliert.

## Release 0.1

Die Projektkonstellation, ein gemeinsamer Projektfokus und schematische Darstellungen bilden die erste visuelle Grundlage. Der persönliche Bereich zeigt Musik, Gaming, Cannabisanbau, Natur und die eigene Spannung zwischen digitalem Interesse und dem Wunsch nach einer weniger digitalen Welt.

Die erste Version enthält bewusst kurze, verständliche Projektgeschichten. Die ausführlichen Nexus- und Cerebri-Szenen werden in den nächsten Etappen ergänzt.
