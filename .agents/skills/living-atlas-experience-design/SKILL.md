# Living Atlas — World Experience Design

## Activation

Use this skill to move from a world idea to a **production-quality, testable, unique** world. Read the full project V4 Master Architecture + World Blueprints + Design System before changing code. Existing G1 3D/History/Canvas contracts are non-negotiable. External Taste design skills may augment this process, never override project facts.

## Workflow

1. **Understand:** identify selected WorldId, visitor goal, real project sources and 1 signature interaction. Gather prior screenshots and relevant React/R3F code. Verify G1 status.
2. **Storyboard:** define Wide, Approach and Detail poses in actual world coordinates, one original silhouette and one visually measurable action/response. Sketch Desktop and Mobile layout, including safe hit areas and orientation.
3. **Art direction:** use strategic empty space, atmospheric layers and distinctive materials. Avoid generic mesh balls, grids everywhere, gratuitous bloom, permanent UI sidebars, standard SaaS cards or copy-heavy explanations.
4. **State before effect:** model nodes/relations/rules as deterministic TypeScript state. Ensure visual line/light/state updates are driven by the model and traceable. Use verified facts; anything illustrative is clearly separated.
5. **Build:** use existing SceneRegistry, SceneDirector, CameraRig, WorldCanvas, asset strategy and semantic HTML. No second canvas or history manager; no JS/WebGL-only content.
6. **Interact:** test drag/wheel/pinch, focus, back, cancel, search/filter if applicable, mobile and keyboard. Reduced motion reaches identical destination without long flight.
7. **Look:** take real screenshots after SceneReady **and** painted pixels at 390/1440; inspect visual hierarchy, landmark identity, actual depth and silhouette. Iterate until the result materially differs from G1 greybox.
8. **Report:** commit evidence, CI/Playwright tests and visual before/after; mention external skills genuinely read and their concrete influence.

## Definition of Done

No ready badge based solely on DOM canvas existence. No purely decorative click. No unsourced claims. No 3D object that is only a replacement for text label. Big world must extend beyond viewport, or intimate world must have equivalent manipulable depth. Informational parity in DOM; exact pose/history returns; actual material/color/geometry differences; readable mobile. If art gate fails, iterate before adding another world.
